# TIPE — Portable Visual Training Device for Athletes

This repository contains the deliverables of my **TIPE (Travaux d’Initiative Personnelle Encadrés)**, completed between **September 2023 and June 2024** as part of the French engineering school entrance examinations.

## Overview

The goal of this project was to design and build a portable and affordable visual reaction training device for athletes of any levels. Professional reaction-training systems used by high-level athletes are often expensive, bulky, and limited to large sports facilities. This project focused on creating a compact and transportable prototype that could also be accessible to non-professional athletes and individuals looking to improve their reaction speed and visual responsiveness.

The project was inspired by the research of Italian doctor, A. Segnalini, whose work demonstrated the importance of visual training in improving overall athletic performance.

## Project Description

I designed and built a working prototype powered by an Arduino microcontroller. The system operates using LEDs that light up randomly on a self designedboard. The user must react as quickly as possible by pressing the corresponding buttons. The training logic, timing system, and interaction flow were fully implemented in embedded C/C++ on Arduino.

The prototype was designed using principles inspired by ophthalmology-based vision testing and visual training methods, particularly visual field analysis techniques (*champ visuel*). These studies were used to determine the optimal LED layout and positioning in order to maximize visual stimulus perception and improve users’ reaction times as effectively as possible.
